# How to use
This is a web app to be installed in a server. Below is the instruction. 
1. Clone this git repository to your server machine.
```
git clone https://github.com/junohBede/money_thing.git
```
2. Install library if needed. 
```
pip install flask
```
3. Activate the app.
```
cd money_thing
python app.py
```
4. Open the app with the link (your server machine's ip):5000
5. Enjoy the app! 
The weekly budget  variable can be set in line 565 of `index.html`.
